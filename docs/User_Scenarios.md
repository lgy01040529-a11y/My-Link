# [User Scenarios] 마이링크 사용자 시나리오 (V2)

마이링크(My Link) 서비스에서 발생할 수 있는 모든 사용자 행동 시나리오를 정의합니다.

---

## 1. 방문자 시나리오 (Visitor Scenarios)

- **페이지 접속**: 사용자는 소유자의 다양한 온라인 활동을 확인하기 위해 공유된 URL(예: `domain.com/lgy`)로 접속한다.
- **프로필 탐색**: 사용자는 소유자의 정보를 파악하기 위해 상단의 아바타, 실명(Username), 닉네임 및 소개글을 읽는다.
- **링크 클릭 및 이동**: 사용자는 소유자의 다른 채널로 이동하기 위해 목록의 링크 버튼을 클릭하며, 이때 시스템은 **해당 링크의 클릭 횟수를 자동으로 기록(Count +1)**한다.
- **아이콘 인지**: 사용자는 링크의 목적지를 직관적으로 알기 위해 구글 API로 추출된 파비콘 아이콘을 확인한다.

---

## 2. 소유자 시나리오 (Owner Scenarios)

### 2.1. 가입 및 초기 설정
- **간편 시작**: 사용자는 별도 가입 없이 구글 로그인을 통해 즉시 자신의 관리 페이지에 진입한다.
- **자동 핸들 할당**: 사용자는 최초 로그인 시 지메일 아이디 기반으로 자동 설정된 `displayName`을 통해 자신의 고유 페이지가 생성되었음을 확인한다.
- **초기 링크 등록**: 사용자는 아무런 링크가 없는 초기 상태에서 '새 링크 추가' 안내에 따라 첫 번째 URL을 등록한다.

### 2.2. 프로필 및 링크 관리 (인라인 편집)
- **정보 실시간 수정**: 사용자는 프로필 정보(실명, 소개글 등)나 링크 제목/URL을 수정하기 위해 해당 영역을 직접 클릭하여 인라인으로 편집하고 저장한다.
- **링크 추가 및 인지**: 사용자는 새로운 링크를 추가한 후 즉시 해당 링크의 파비콘이 정상적으로 노출되는지 확인한다.
- **링크 삭제**: 사용자는 더 이상 필요 없는 링크를 목록에서 즉각 제거하기 위해 삭제 버튼을 클릭한다.

### 2.3. 성과 확인 및 공유
- **링크 클릭수 확인**: 사용자는 자신의 콘텐츠 중 어떤 것이 인기 있는지 파악하기 위해 각 링크별로 기록된 클릭 카운트 숫자를 확인한다.
- **URL 홍보**: 사용자는 자신의 마이링크를 널리 알리기 위해 고유 주소를 복사하여 인스타그램, 트위터 등 SNS 프로필에 등록한다.

### 2.4. 예외 및 특수 상황
- **닉네임 중복 방지**: 사용자는 `displayName`을 수정할 때, 이미 다른 사용자가 점유 중인 닉네임인 경우 시스템의 안내를 받고 다른 값을 입력한다.
- **로그아웃**: 사용자는 계정 보호를 위해 관리 작업을 마친 후 안전하게 로그아웃한다.
- **잘못된 URL 입력**: 사용자가 유효하지 않은 URL을 입력한 경우, 시스템의 안내를 받아 정확한 주소로 수정한다.
