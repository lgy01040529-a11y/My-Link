# [PRD] 마이링크 (My Link) - 기능 정의서

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (My Link)
- **목적**: 사용자의 다양한 온라인 정체성을 하나의 페이지에 통합하여 제공하는 간결하고 실용적인 링크 관리 서비스입니다.
- **대상 사용자**: 개발자 및 크리에이터 등 자신만의 통합 링크 페이지가 필요한 모든 사용자

---

## 2. 핵심 기능 목록

### 필수 기능
- **Firebase 기반 구글 로그인**: 서비스 이용의 유일한 인증 수단
- **프로필 관리**: 구글 프로필 사진 활용, 실명(Username), 닉네임(DisplayName - 지메일 앞부분 자동 설정) 및 한줄 소개 수정 기능
- **닉네임 기반 URL (Slug)**: `DisplayName`을 페이지 URL 슬러그로 사용 (예: `domain.com/[displayName]`)
- **링크 관리 (인라인 편집)**: 
  - 링크 제목 및 URL 추가/삭제
  - 목록에서 직접 수정할 수 있는 **인라인 편집(Inline Editing)** 방식 적용
  - 모든 편집 영역 옆에 **연필 아이콘(✏️)**을 상시 노출하여 직관성 확보
- **관리자 전용 기능**: 화면 우측 상단에 **'내 페이지 보기'** 버튼 고정 노출
- **반응형 웹 UI**: 모바일 최적화 레이아웃

### 기능 제약 사항 (미지원)
- 이미지 업로드 기능 없음 (구글 프로필 이미지 유지)
- 별도의 테마 선택 및 커스터마이징 기능 없음
- 링크 활성화/비활성화, 드래그 앤 드롭 순서 변경 기능 없음

## 3. 상세 사양

### 3.1. 사용자 인증 및 프로필
- **사용자 식별**: Firebase Auth (Google Provider)
- **사용자 정보 구분**:
  - **Username**: 프로필 상단에 크게 노출되는 실제 사용자 이름
  - **DisplayName**: URL 주소에 사용되는 유니크한 슬러그. **최초 로그인 시 구글 이메일의 앞부분(@ 이전)으로 자동 설정**됩니다.
- **URL 식별자**: `DisplayName`을 URL의 경로(Path) 슬러그로 사용
- **프로필 수정**: 닉네임과 한줄 소개는 마이페이지(또는 인라인)에서 즉시 수정 가능

### 3.2. 링크 및 아이콘
- **인라인 편집**: 별도의 수정 페이지 이동 없이, 리스트 아이템의 텍스트를 클릭하여 즉시 수정 및 저장
- **파비콘 추출**: `https://www.google.com/s2/favicons?domain=[link_url]&sz=64` 형태의 구글 API를 활용하여 링크 아이콘 표시

### 3.3. 데이터 모델링 (Firestore)
- **users 컬렉션**:
  - `uid`: 고유 ID
  - `email`: 계정 이메일
  - `username`: 실제 노출용 이름 (실명 등)
  - `displayName`: 닉네임 (URL 핸들로 활용)
  - `photoURL`: 구글 프로필 이미지 URL
  - `bio`: 한줄 소개 (편집 가능)
- **links 서브 컬렉션**:
  - `title`: 링크 제목 (인라인 편집 가능)
  - `url`: 연결 주소 (인라인 편집 가능)

## 4. 기술 스택
- **Frontend**: Next.js (App Router), Tailwind CSS
- **Backend**: Firebase Auth, Cloud Firestore
- **External API**: Google Favicon API
